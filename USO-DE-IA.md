# Uso de inteligencia artificial

La consigna permite usar IA y pide contar en qué la usamos. Cada integrante agrega su parte abajo.

## Armado inicial del proyecto (Claude Code)

Usamos Claude (Claude Code) para preparar la base del repositorio **antes** de repartir el trabajo:

- Analizar la consigna y proponer la arquitectura: núcleo común, consola y API.
- Definir el contrato: endpoints, schemas, firmas de clases y métodos con sus docstrings.
- Escribir la suite de tests, que es la especificación de cada flujo.
- Generar los datos de prueba (`data/seed.json`), algo que la consigna permite explícitamente.
- Redactar la documentación inicial (`README`, `docs/`).

**No** usamos IA para implementar las estructuras de datos (lista, árboles, pila, cola) ni los servicios. El repositorio arrancó con esos cuerpos vacíos (`NotImplementedError`) y cada integrante los programó para que pasen los tests.
